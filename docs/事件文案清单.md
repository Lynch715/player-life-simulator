# 事件文案增强 · 工作表

目标：给现有事件补更有画面、有台词的正文，让故事更精彩——**但不写成小说**。

## 写作规范（重要）
- **长度**：每条正文目标 **3–6 句 / 约 120–220 字**（现在多是 1–2 句、40–60 字）。够有画面和一两句台词即可。
- **只改叙事**：选项文字、数值效果、触发条件都别动（那是游戏逻辑）。你只写/扩「正文叙事 + 台词」。
- **台词**用「」或引号，我会自动套高亮样式。
- **选项反应（可选）**：想给某个选项加一句「选完后的即时反应」也行，一句话，我用日志行落地。不强制。
- **别平均用力**：⭐⭐⭐ 重点写；⭐ 的（暗雷/健康/国家队战术）保持简洁，甚至可以不动。

## 交回格式
标 id + 正文即可，例如：
```
xiaoman_exam →
「你把她落在桌上的准考证攥在手里……（你的正文）」
（选项反应，可选）送她去考场：她在考场门口回头冲你摆手，你转身狂奔向球场。
```
选项要改就一起说；不说我沿用原选项。
