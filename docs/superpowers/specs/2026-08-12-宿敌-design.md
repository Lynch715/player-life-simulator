# 宿敌：江彻

日期：2026-08-12

## 问题

这个游戏的世界是静止的。16支中超队、20支英超队的实力是写死的常量，你踢十年，上海海港永远79；金靴、金球、首发率都是你和一串数字的关系，没有一个**具体的人**在和你抢东西。

生涯模拟的核心黏性来自"我在一个活的世界里留下痕迹"。现在的痕迹只有你自己的：25岁之后系统上没有新东西进来，月循环退化成数值爬坡。玩家需要一个和他同期出道、一路互相较劲的对手——每个赛季都在回答同一个问题：**今年，你和他，谁更强？**

## 实测到的现状

用 12 局随机行动的完整生涯测出玩家各年龄段的赛季进球（standard 难度）：

| 年龄段 | 赛季进球 | 综合能力 |
|---|---|---|
| 14–15（梯队） | 0–5，中位 1–2 | 61–64 |
| 16–17（分流期） | 0–14，中位 5 | 67–71 |
| 18–24（职业前期） | 0–16，中位 7–9 | 73–84 |
| 25–33（巅峰） | 3–22，中位 9–14 | 85–91 |

宿敌的进球必须校准进同一个带宽，对位才有悬念。梯队一季只有 3 轮、样本太小，进球对位从 18 岁职业期才开始；14–18 岁他只活在剧情里。

## 决定

- **一个作者化的角色，不是随机名字。** 他叫**江彻**，和你同届的铜梁龙梯队前锋，14岁时就是"天才是他、努力是你"的那一个。这游戏的人物（林小满、周骁）全是作者化写法，宿敌照做——有性格、有台词，才配得上十几年的对手戏。不画立绘（见"不做"）。
- **生涯镜像**：16岁分流时他走你没走的那条路（你留国内他去海外，你去海外他留中超）；18岁他签约职业俱乐部，之后每2–3个赛季可能转会（种子决定）。你们可能同联赛同场竞技，也可能隔空对照。
- **对位之争，不是联赛金靴。** 头对头比的是**双方的联赛进球**（实施中修订：你的 seasonStats.goals 混着杯赛和世预赛，他的数字只有联赛——拿总数比联赛，随机行动的机器人都能七成赛季压过他。玩家的联赛进球单独记在 seasonStats.leagueGoals）。这个定义在跨联赛时依然成立，也绕开了给全联盟建个人数据的深坑（积分榜设计里已明确否决过完整射手榜）。
- **从 18 岁开始计分。** 14–18 岁他通过事件和半年剧情出场，不比数字。

## 第一节 · 数据与成长

### 新增状态

```js
s.rival = {
  name:"江彻",
  level,        // 综合能力，与玩家 overall 同一量纲
  club,         // {name, league, strength}
  route,        // 16岁分流走的路（镜像玩家）
  goals,        // 本赛季进球
  careerGoals,
  duels:{win:0,loss:0,draw:0},   // 赛季头对头历史战绩
  injuredRounds, // 本赛季伤停剩余轮数
  season         // 赛季号，翻季结算并重置
}
```

### 成长曲线：软回归，不是橡皮筋

`level` 每赛季初重算：**年龄基线 + 向玩家 overall 的软回归 + 赛季状态**。

- 年龄基线：14岁 = 玩家初始 overall + 3（他起点就比你高）；此后按玩家实测曲线的斜率走，30岁起衰退。
- 软回归：若 |level − 玩家overall| > 6，向玩家方向拉回到差距 6。**差距上限 ±6**。
- 赛季状态：按（赛季号, "rival"）种子 roll ±2，让他也有小年大年。

否决的两个方案：

- **纯静态曲线**：玩家练得快或慢，第3个赛季后对位胜负就永远定死了，之后十年都是垃圾时间。
- **完全橡皮筋（永远贴着玩家）**：假。玩家会发现无论怎么练都五五开，对位立刻失去意义。

±6 的软回归是折中：你连续摆烂他会甩开你（追赶戏），你练猛了他咬着你（防守戏），但胜负始终由你最近的表现主导。

### 进球从哪来

- **同联赛**：他的俱乐部本来就在你的积分榜上。每轮 `advanceLeagueRound` 模拟出他的球队比分后，他个人分走其中 `poisson` 份额（由 level 与球队 strength 决定），他的进球和榜上他球队的进球**永远对得上**。
- **跨联赛**：他的联赛不在你的榜上，按同样的公式独立生成，每当你的联赛推进一轮，他那边也推进一轮（两边赛季轮数本来就同为12）。
- 种子按（赛季, 轮次, "rival"）派生——读档、重渲染不改历史，与积分榜同一纪律。
- **伤病**：每赛季初种子 roll 一次，约 15% 概率赛季中伤停 2–3 轮。制造"他伤了你趁机拉开"的年份差异。
- 校准目标：他的赛季进球分布落在 **5–15、中位 9 上下**，与玩家实测带宽一致。写测试钉住（见"验收"）。

## 第二节 · 呈现与接线

### 生涯页 ·「宿敌」卡

放在生涯时间线旁边，复用 `.info-card`：

```
宿敌 · 江彻                     利兹联 · 英超
本赛季对位    你 11 球 : 9 球 他
生涯对位      你 4 胜 · 2 平 · 3 负
[一行自动状态文案：他上个月帽子戏法上了头条 / 他伤了，赛季报销两轮]
```

### 三处接线

1. **赛前预告**：同联赛且本轮对阵他的俱乐部时，预告加一行"江彻在对面首发"。这场赢下头对头（你比他这场进球多）额外 +1 状态，输给他 −1——数值刻意小，压力主要靠文案给。
2. **年度评选**：`queueAward` 的 modal 里加一行本赛季对位结果（"你 12 球，江彻 14 球——今年他压你一头"），并写进 `duels`。**不改金球评选公式**——对位是叙事层的胜负，不参与评选指数，避免平衡连锁。
3. **事件**：每赛季第 2 个月触发一条宿敌事件（现有 `queueEvent` 框架，按阶段分池：梯队 / 分流 / 职业前期 / 巅峰 / 暮年，各 2–3 条）。事件给的是小额状态/意志变化和台词，不给属性。

### 成就与荣誉

- 新成就 3 个：「第一次压过江彻」「连续 3 个赛季压过他」「生涯对位领先退役」。
- 退役结局文案增加一个分支变量：生涯对位领先/落后时，结局里江彻出场的那句话不同。

### 存档兼容

不升 VERSION。`normalizeSave` 补 `if(d.rival===undefined)d.rival=null`；老档在下一个赛季初自动生成江彻（`duels` 从 0 起算，之前的赛季不补账）。

## 不做

- **同队抢首发**：牵动 `startChance`、教练信任、转会意愿一整串，且"他转会到你队"的边界情况多。另开一轮。
- **完整射手榜**：积分榜设计里已否决，理由不变。
- **宿敌进国家队和你抢位置**：国家队线已经很密（世预赛/亚洲杯/世界杯），再塞人会稀释主线。
- **立绘**：新增一张立绘要走美术流程，先用纯文字出场；写好了自然会有画他的一天。
- **多个宿敌 / 宿敌可配置**：一个写透比三个写薄强。
- **他和你互转会到同一队**：见"同队抢首发"。
- （另案）**争冠天王山标记**与**赛季间实力漂移**：都是好改动，但和本设计正交，各自单独开单子。

## 验收

- `node --check app.js && node tests/structure.test.mjs` 全绿，**连跑 30 次**
- 新增测试：
  - 江彻 18 岁起存在，`level` 与玩家 overall 差距永不超过 ±6（软回归钉住）
  - 同联赛时，他的赛季进球 ≤ 榜上他球队的总进球（份额自洽）
  - 同一存档反复推进/重渲染，他的进球与 level 不变（种子确定性）
  - 200 次模拟赛季：他的进球 P5–P95 落在 2–20 内，中位 7–11（带宽校准）
  - 赛季末 `duels` 恰好增加一场胜/平/负
  - `normalizeSave`：老档补 `rival:null`，下个赛季初自动生成
- 长跑回归：10 局完整生涯，无崩溃、对位计数与赛季数对得上、无跨赛季脏数据
- 弯引号计数 `grep -o "“" app.js | wc -l` 保持 243（新增文案用弯引号后更新基线并写进计划）
- 重建单文件版 `python3 build_single.py`
