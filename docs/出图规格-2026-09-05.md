# 出图规格 · 2026-09-05 荣誉室与结算海报批次

承接 `docs/出图规格-2026-08-31.md`。本批服务于三件事：**五大联赛 + 欧战体系**、**荣誉室独立成页**、**结算海报重做**。四组共 **30 张**，按优先级排：

| 组 | 张数 | 优先级 | 目的 |
|---|---|---|---|
| A · 奖杯图标套组 | 14 | ★★★ 必须 | 荣誉室陈列、结算海报奖杯架、夺冠弹窗——全游戏的奖杯从此有实物 |
| B · 评级印章 | 5 | ★★★ 必须 | 结算海报的视觉中心，S/A/B/C/D 五档 |
| C · 海报底纹 | 3 | ★★ 建议 | 结算海报的底，取代现在的纯渐变 |
| D · 联赛与赛事徽记 | 8 | ★ 有余力再出 | 转会页、赛程页、荣誉室分区标题 |

**和上一批的根本区别**：上一批是场景图（人、球场、氛围），这一批是**物件图**——单个奖杯、单枚印章、一块纹理。规格因此完全不同，不要套用上一批的安全区和景别要求。

## 一、技术规格

### A / B / D 组（物件图，透明底）

| 项目 | 要求 |
|---|---|
| 尺寸 | **1024×1024 正方形** |
| 背景 | **透明 PNG**。在 GPT 里明确要求 "transparent background"。如果某张就是出不了透明，改用**纯品红底 `#FF00FF`**，我这边抠掉——不要用白底或黑底，金属反光里会混进底色 |
| 主体位置 | 居中，主体占画面 **60%–80%**，四周留至少 10% 空白。我会在代码里缩放和摆放，留白是给我裁切余量 |
| 视角 | 正面微俯视（约 10°），一套图视角必须一致 |
| 光线 | 柔和棚拍光，左上主光 + 右侧弱补光，底部有柔和接触阴影（阴影可以画在透明层上） |
| 禁止元素 | 任何文字、字母、数字；真实奖杯造型（大耳朵杯、沙拉盘、雷米特金杯、荷叶杯等都不能照抄）；真实联赛 / 俱乐部 / 品牌标识 |
| 命名 | 见每张下方"文件名"，落地转 `.webp`（WebP 支持透明通道，直接转不丢 alpha） |

### C 组（底纹，不透明）

| 项目 | 要求 |
|---|---|
| 尺寸 | **1024×1536 竖版**（GPT 能出的最接近尺寸；海报是 1080×1920，我按高度铺满后左右各裁 100px，纹理无主体所以裁掉不心疼） |
| 背景 | 不透明，铺满 |
| 内容 | **纯纹理，无任何主体、无文字、无边框**。边框和金线由我在代码里画，图只提供"材质" |
| 明度 | 整体偏暗（平均明度 15%–25%），因为上面要压白色和金色文字 |

### 一致性要求（最重要）

奖杯 14 张必须看起来是**同一个工匠做的同一套**。做法：

1. **先出 A1（中超奖杯）**，调到满意为止
2. 之后每张都把 A1 的成图作为参考图一起喂进去，提示词里加一句 "same rendering style, lighting, camera angle and material quality as the reference image"
3. 尽量在**同一个会话**里连续出完 A 组，中途不要换会话

B 组 5 枚印章同理，先出 B1 再以它为参考。

## 七、交付与接入对照

出图后：PNG 原图放 `art-source/`，转 WebP 进 `assets/`。透明图转 WebP 时**不要**加 `-alpha_q` 之类会压 alpha 的参数：

```bash
# 有 cwebp
cwebp -q 85 -exact art-source/trophy-ucl.png -o assets/trophy-ucl.webp

# 没有就用 Python（保留透明通道）
python3 -c "from PIL import Image; Image.open('art-source/trophy-ucl.png').convert('RGBA').save('assets/trophy-ucl.webp','WEBP',quality=85,method=6)"
```

| 组 | 接入位置 | 要改的代码（我来） |

## 八、验收清单

**A / B / D 组每张：**

- [ ] 1024×1024，背景透明（或纯品红 `#FF00FF`）
- [ ] 主体居中，占画面 60%–80%，四周留白 ≥10%
- [ ] 没有任何文字、字母、数字
- [ ] 没有照抄现实中的著名奖杯造型
- [ ] 与同组第一张的视角、打光、渲染风格一致
- [ ] B 组：中央圆面**空白**，没有任何刻字或图案
- [ ] A 组：14 座奖杯并排放在一起时每座都能一眼分出来

**C 组每张：**

- [ ] 1024×1536，铺满，无主体无边框
- [ ] 整体偏暗，直觉上能在上面读清白字

快速自检方法：把 A 组 14 张缩到 128×128 排成一行看——如果这时候还能分清谁是谁，荣誉室里就没问题；如果有两座糊成一样，说明轮廓差异不够，重出其中一座。
