# 关键场景立绘出图规格

用于：杯赛捧杯、洲际夺冠、联赛夺冠、金靴、金球奖弹窗。
本规格已按“PNG 原图 → 统一 WebP → 弹窗接入 → 单文件重建”的链路落地。PNG 原图保留在生成工作区，项目内交付 WebP，避免运行时加载大体积源图。

## 通用风格前缀（每张提示词都带上）

> 半写实数字绘画风格，电影感打光，深色夜场足球场背景，主色调深绿与藏青、金色点缀。主角是同一位17-25岁中国男性前锋：利落黑色短发、剑眉、轮廓分明、身材精瘦挺拔。画面中不要出现任何文字、字母、数字、真实俱乐部队徽或品牌logo。构图主体居中，画面左右两侧可能被裁切。

## 技术规格

| 项目 | 要求 |
|---|---|
| 方向与比例 | 竖版，约 2:3（如 1024×1536） |
| 交付格式 | PNG 原图（勿压缩，后续统一转 webp） |
| 脸部位置 | 画面上部 1/5 ~ 1/3 处（弹窗聚焦顶部 18%） |
| 主体位置 | 水平居中（移动端会横向裁切两侧） |
| 禁止元素 | 文字/字母/数字、真实队徽、品牌logo、水印 |
| 数量 | 4 张必出 + 1 张可选 |

## 各场景提示词

### 1. 联赛夺冠 `league-title-scene`

> 主角身穿深绿藏青渐变球衣，站在颁奖台上双手高举一座金色联赛奖杯，仰头呐喊，金色彩带和碎纸屑从夜空落下，身后是灯光璀璨的看台人海，逆光轮廓，金色光斑弥漫。

### 2. 杯赛捧杯 `domestic-cup-scene`（足协杯/足总杯共用）

> 主角单膝跪在草皮上亲吻一座银色高脚奖杯，夜雨刚停，草皮反光，身后队友模糊的欢庆剪影，一束顶光打在奖杯和主角侧脸上，安静而庄重的氛围，与狂欢形成反差。

### 3. 洲际之夜 `continental-cup-scene`（亚冠/欧冠共用）

> 主角背对镜头回头望向观众，肩上披着球队围巾，面前是一座巨大的银色双耳奖杯立在展示台上，体育场夜空中有探照灯光柱交错，蓝银色调为主、少量金色，史诗感、朝圣感。

### 4. 金靴 `golden-boot-scene`

> 特写构图：一只金色足球鞋奖座摆在深色丝绒底座上占画面下半部，主角在背景虚化处抱臂而立看着它，嘴角微扬，暗金色调，一束侧光，像奢侈品广告一样的质感。

### 5. 金球奖 `ballon-scene`（可选）

> 主角身穿深色西装站在颁奖礼舞台聚光灯下，双手捧起一座金色球形奖杯，全场暗下只有一束顶光落在他身上，庄重、克制、巅峰时刻。
