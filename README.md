# 模拟球员 · 绿茵人生

从14岁梯队球员开始的本地足球生涯模拟游戏。

在线游玩：https://lynch715.github.io/player-life-simulator/

## 启动

直接双击 `index.html` 即可游玩。也可以在本目录执行：

```bash
python3 -m http.server 8766
```

然后访问 `http://127.0.0.1:8766/`。

## 已实现

- 七项主属性 PAC 速度 / SHO 射门 / PAS 传球 / DRI 盘带 / DEF 防守 / PHY 身体 / WIL 意志，首页七边形雷达图展示
- 创建时独立选择身高档位（矮174 / 中182 / 高191，影响 PHY/PAC/DRI 初值，不占分配点），另有24点分配七项属性
- 20个足球天赋随机抽3个、玩家命名
- 14—16岁梯队成长，每月3执行点，每2个月无重复优先的艰难事件
- 每半年关键人物剧情；父亲、林小满、周骁教练独立立绘
- 16岁国内一线队 / 校园 / 海外青训三线分流；海外邀请三选一（英格兰固定在列，另两家按存档从西班牙/德国/意大利/法国抽），18岁按表现升入该国豪门一线队或转投中下游球队
- 18岁职业市场：中超16队 + 英超20 / 西甲20 / 德甲18 / 意甲20 / 法甲18，六个联赛一张 `LEAGUES` 配置表（分档、国内杯赛、洲际名额、评选加权、转会门槛、射手榜人名池、梯队后缀），转会门槛按联赛不同
- 所有行动与比赛判定统一经由「有效属性」= 属性 × 状态体能系数；体能见底时身体和速度掉得最狠，意志几乎不受影响
- 有效属性、对手强度和随机共同决定的比赛简报与伤病
- 同月多场：一个月最多三场——联赛（每月一场）+ 杯赛或洲际（同月并存，不再挤掉联赛）+ 国家队友谊赛/世预赛；一场踢完弹简报，按「继续」进下一场的赛前预告，中途受伤剩下的场次自动标缺阵；同月第二、三场体能消耗略低，月度恢复上调；大赛决赛圈月你不在俱乐部，当月没有俱乐部比赛
- 赛季赛程在赛季初就排定：主界面常显下一场对手、主客与还有几个月（同月多场会标「该月 N 场」，日程页每行标 1/2、2/2），「赛程」页可查一整季日程（含国家队友谊赛与三大赛，末尾还标出赛季收官的评选月），伤停缺阵的场次也会留痕
- 「结束本月」后先出赛前预告——写明对手、双方实力星级（FIFA 式五星）、你的体能状态与预估首发率，三个选项就是本场职责（专注禁区/回撤组织/疯狂逼抢），看完对手再决定怎么踢
- 每场出场触发 2 个关键时刻，成功率由关键属性、状态、体能、天赋与流派共同决定并锁在 15%—85%
- 高风险选择成功可进球、评分大涨并留下「经典之战」；失败则浪费机会，还有 35% 概率被对手打反击
- 每 3 场一轮教练挑战，稳妥/进攻/冒险三选一；失败只扣少量状态，不扣信任，避免越输越难
- 四条训练流派（禁区杀手 SHO / 爆点前锋 PAC·DRI / 支点中锋 PHY·DEF / 组织型前锋 PAS），20/60/120 经验三级成长，二级解锁专属比赛选项；流派等级抬高对应属性的成长天花板，没有流派兜着的属性练到88左右就爬不动了
- 五条训练各自直连属性，其中「前场逆抢」是 DEF 的成长入口；赛前选「疯狂逼抢」在 DEF 不足时是净负收益
- 同月重复同一训练收益降至 60%、伤病风险上升；行动组合有额外奖励；未用完的执行点自动转为休息
- 国家队征召、陌生位置、国家队伤病；友谊赛每半年一场，和大赛一样排进赛程，主界面与日程页都提前看得到
- 国家队大赛日历：20/24/28岁亚洲杯、21/25/29岁世预赛、22/26/30岁世界杯，23/27岁留空给俱乐部线。世预赛六轮摊在整整一年里逐场可玩，你的进球直接决定积分和出线；决赛圈七场每场都先选临场基调再走一个关键时刻，平局进点球。亚洲杯与世界杯共用同一套引擎，难度差别只来自对手池——亚洲最强的日本 85，世界杯淘汰赛池 84~93
- 亚洲杯与世界杯触发时显示专属赛事画面；抽签、逐场对阵和战报都带中国国旗与对手国旗，夺冠后的领奖台对话加入奖杯视觉
- 联赛积分榜：每个联赛各有一张，你的每一场都直接算进排名；赛季末排第一就是冠军（不再掷骰子），榜尾三名算保级失败；榜上画出资格线——洲际正赛区（金）/ 次级洲际区（蓝）/ 降级区（红）
- 联赛射手榜与金靴：每队一名具名射手（虚构人名，按联赛语种分中/英/西/德/意/法六套人名池），进球随积分榜同一套确定性引擎逐轮累计；江彻在你的联赛时榜上就是他本人。赛季末射手榜第一拿「联赛金靴」，进荣誉室与年度评选战报
- 国内杯赛：足协杯 / 足总杯 / 国王杯 / 德国杯 / 意大利杯 / 法国杯，每赛季三轮淘汰赛排进赛程（与国际比赛日永不相撞）；平局踢点球（意志判定），决赛夺冠得奖杯、声望与奖金；伤停缺阵球队照踢
- 亚冠 / 欧冠 / 欧联：上赛季联赛名次决定资格——欧洲联赛前 4 进欧冠、其后 1–2 名进欧联，中超前 2 进亚冠；四轮赛制：联赛阶段生死战 → 八强 → 半决赛 → 决赛（联赛阶段平局擦线出线，淘汰赛平局进点球）；欧冠对手池是五大联赛 83+ 的强队加本菲卡/波尔图/阿贾克斯等欧洲豪门，欧联 74~84，亚冠为亚洲强队加中超前列；同一季不会两次碰到同一支队；欧冠冠军是分量最重的俱乐部荣誉之一
- 赛事荣誉立绘：联赛冠军、足协杯/足总杯、亚冠/欧冠、金靴与金球奖各有专属 2:3 场景图；夺冠/年度评选弹窗按荣誉自动配图，移动端保留人物与奖杯主体
- 宿敌江彻：同届梯队的天才前锋，16岁走你没走的那条路，18岁起每个赛季和你比联赛进球；同联赛对阵会当场较量，年度评选揭晓对位胜负，退役结局有你们各自的收尾
- 金球奖按联赛加权（英超/西甲 +6 … 中超 −6）且进球按联赛含金量折算（中超 ×0.75），在中超刷 30 球不等于在欧洲刷 30 球
- 荣誉室（独立标签页）：本局生涯的博物馆——按含金量分区的展柜（国家队大赛 / 洲际 / 联赛 / 杯赛 / 个人奖项），同名荣誉合并成一件展品标 ×N 与年份，空位用灰影奖杯提示下一个目标；个人纪录九宫格（出场、进球与首球年龄、单季最高进球、最高评分、帽子戏法、经典之战、国家队出场、生涯最高能力）；逐赛季荣誉时间线
- 档案馆（原「排行」）：跨存档的成就系统与本地生涯排行合并在一页
- 奖杯实物图 14 座（六个联赛各一座、国内杯、欧冠、欧联、亚冠、金靴、金球、世界杯、亚洲杯）与联赛/赛事徽记 8 枚：荣誉室展柜、夺冠与年度评选弹窗、结算页奖杯架、转会报价卡和积分榜标题都用上了
- 金球奖、联赛冠军、21项成就（「登陆五大联赛」取代原「登陆英超」）、本地生涯排行
- 三档难度（标准/困难/严酷）：影响成长速度、属性软上限、伤病、征召门槛与收入
- 30岁起身体机能逐年衰退，34岁左右或状态崩盘自动退役并结算生涯结局
- 合同月薪逐月发放、生活开销与欠款利息，金钱可用于礼物/家用/康复并计入生涯积分
- 每赛季教练KPI目标，达成给奖金与信任，失败会被雪藏、降薪甚至降级
- 分手后可复合支线（含海外线），关系值越高，比赛发挥与状态加成越大
- 关系值满且成年后的亲密里程碑，解锁“和小满独处”行动（状态↑体力↓）
- 家庭状况与小满关系并列显示在侧栏，两者都抬高状态的长期基线：家里安稳你状态更稳，家里出事你持续下滑（寄钱回家、父亲生病这类事件从此有了真实数值作用）
- 校园联赛对手为重庆本地校队；侧栏常显资金，独立“资产”页 19 件商品分五类（训练/家庭/生活/投资/感情），含被动收入与求婚结婚，按年龄·声望·前置资产分级解锁
- 每次行动给出随机剧情反馈，行动页横幅与故事日志同步展示
- 生涯结算页：主视觉按含金量最高的荣誉自动选场景图（世界杯>金球>洲际>联赛>金靴>杯赛>球员立绘）；评级旁压一枚印章（巨星 S 金钻 / 顶级 A 金 / 合格 B 银 / 短暂 C 青铜 / 其余 D 铸铁）；奖杯陈列、本局成就时间线（几岁解锁什么）、转会轨迹、「生涯中的人」立绘收尾语一页看完；支持导出 PNG 结算海报与 TXT 生涯战报，file:// 画布受限时自动退回文本导出
- 结算海报 1080×1920 重做：按评级选底纹（丝绒 / 皮革 / 混凝土）+ 双金线画框与四角饰；左侧 2:3 竖版主视觉不再被横裁，右侧姓名、评级印章（字母由画布压上）与评语；六格数据、奖杯架（奖杯实物图按含金量排、同名合并 ×N、标年份）、转会轨迹、生涯中的人立绘条
- 本机自动存档，无后端、无外部CDN、无数据上传
