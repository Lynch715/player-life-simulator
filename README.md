# 模拟球员 · 绿茵人生

从14岁梯队球员开始的本地足球生涯模拟游戏。

在线游玩：https://lynch715.github.io/player-life-simulator/

## 启动

直接双击 `index.html` 即可游玩。也可以在本目录执行：

```bash
python3 -m http.server 8766
```

然后访问 `http://127.0.0.1:8766/`。

## 已实现

- 七项主属性 PAC 速度 / SHO 射门 / PAS 传球 / DRI 盘带 / DEF 防守 / PHY 身体 / WIL 意志，首页七边形雷达图展示
- 创建时独立选择身高档位（矮174 / 中182 / 高191，影响 PHY/PAC/DRI 初值，不占分配点），另有24点分配七项属性
- 20个足球天赋随机抽3个、玩家命名
- 14—16岁梯队成长，每月3执行点，每2个月无重复优先的艰难事件
- 每半年关键人物剧情；父亲、林小满、周骁教练独立立绘
- 16岁国内一线队 / 校园 / 海外青训三线分流，海外路线强制分手
- 18岁职业市场，2026中超16队与2026/27英超20队
- 所有行动与比赛判定统一经由「有效属性」= 属性 × 状态体能系数；体能见底时身体和速度掉得最狠，意志几乎不受影响
- 有效属性、对手强度和随机共同决定的比赛简报与伤病
- 赛前三选一的常驻职责（专注禁区/回撤组织/疯狂逼抢），每场出场触发 2 个关键时刻，成功率由关键属性、状态、体能、天赋与流派共同决定并锁在 15%—85%
- 高风险选择成功可进球、评分大涨并留下「经典之战」；失败则浪费机会，还有 35% 概率被对手打反击
- 每 3 场一轮教练挑战，稳妥/进攻/冒险三选一；失败只扣少量状态，不扣信任，避免越输越难
- 四条训练流派（禁区杀手 SHO / 爆点前锋 PAC·DRI / 支点中锋 PHY·DEF / 组织型前锋 PAS），20/60/120 经验三级成长，二级解锁专属比赛选项；流派等级抬高对应属性的成长天花板，没有流派兜着的属性练到88左右就爬不动了
- 五条训练各自直连属性，其中「前场逆抢」是 DEF 的成长入口；赛前选「疯狂逼抢」在 DEF 不足时是净负收益
- 同月重复同一训练收益降至 60%、伤病风险上升；行动组合有额外奖励；未用完的执行点自动转为休息
- 国家队征召、陌生位置、国家队伤病、世界杯模拟
- 金球奖、联赛冠军、奖杯陈列、21项成就、本地生涯排行
- 三档难度（标准/困难/严酷）：影响成长速度、属性软上限、伤病、征召门槛与收入
- 30岁起身体机能逐年衰退，34岁左右或状态崩盘自动退役并结算生涯结局
- 合同月薪逐月发放、生活开销与欠款利息，金钱可用于礼物/家用/康复并计入生涯积分
- 每赛季教练KPI目标，达成给奖金与信任，失败会被雪藏、降薪甚至降级
- 分手后可复合支线（含海外线），关系值越高，比赛发挥与状态加成越大
- 关系值满且成年后的亲密里程碑，解锁“和小满独处”行动（状态↑体力↓）
- 校园联赛对手为重庆本地校队；侧栏常显资金，独立“资产”页 19 件商品分五类（训练/家庭/生活/投资/感情），含被动收入与求婚结婚，按年龄·声望·前置资产分级解锁
- 每次行动给出随机剧情反馈，行动页横幅与故事日志同步展示
- 本机自动存档，无后端、无外部CDN、无数据上传
