# 模拟球员 · 绿茵人生

从14岁梯队球员开始的本地足球生涯模拟游戏。

在线游玩：https://lynch715.github.io/player-life-simulator/

## 启动

直接双击 `index.html` 即可游玩。也可以在本目录执行：

```bash
python3 -m http.server 8766
```

然后访问 `http://127.0.0.1:8766/`。

## 已实现

- 20点五维初始属性、20个足球天赋随机抽3个、玩家命名
- 14—16岁梯队成长，每月3执行点，每2个月无重复优先的艰难事件
- 每半年关键人物剧情；父亲、林小满、周骁教练独立立绘
- 16岁国内一线队 / 校园 / 海外青训三线分流，海外路线强制分手
- 18岁职业市场，2026中超16队与2026/27英超20队
- 能力、状态、体能、对手和随机共同决定的比赛简报与伤病
- 国家队征召、陌生位置、国家队伤病、世界杯模拟
- 金球奖、联赛冠军、奖杯陈列、20项成就、本地生涯排行
- 三档难度（标准/困难/严酷）：影响成长速度、属性软上限、伤病、征召门槛与收入
- 30岁起身体机能逐年衰退，34岁左右或状态崩盘自动退役并结算生涯结局
- 合同月薪逐月发放、生活开销与欠款利息，金钱可用于礼物/家用/康复并计入生涯积分
- 每赛季教练KPI目标，达成给奖金与信任，失败会被雪藏、降薪甚至降级
- 分手后可复合支线（含海外线），关系值越高，比赛发挥与心情加成越大
- 关系值满且成年后的亲密里程碑，解锁“和小满独处”行动（状态↑体力↓）
- 校园联赛对手为重庆本地校队；侧栏常显资金，独立“资产”页 19 件商品分五类（训练/家庭/生活/投资/感情），含被动收入与求婚结婚，按年龄·声望·前置资产分级解锁
- 每次行动给出随机剧情反馈，行动页横幅与故事日志同步展示
- 本机自动存档，无后端、无外部CDN、无数据上传
